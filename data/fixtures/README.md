# Fixtures — SYNTHETIC, not real satellite imagery

Generated by `scripts/generate_fixtures.py` (seed=42, fully reproducible — run it
yourself and you'll get byte-identical images).

Real Sentinel-2/SAR/BigEarthNet data could not be downloaded into the
development sandbox that produced this repo (see
`../../docs/network_constraints.md`). These five PNGs are procedurally drawn
scenes (a blue "lake" blob, a green "vegetation" patch, a gray "urban" grid, on
a brown "soil" background) that exist **only** to prove the ingestion →
validation → routing → specialist → evidence → confidence → trace pipeline
executes correctly end-to-end. Any answer a specialist produces on these files
describes the synthetic pattern, not a real place, and must never be presented
as a real-world result.

| File | Purpose |
|---|---|
| `single_image.png` | Single-image VQA / grounding input |
| `change_before.png` / `change_after.png` | Bi-temporal pair — `after` has one added gray block simulating new construction |
| `fusion_optical.png` / `fusion_sar.png` | Optical + SAR-like pair of the same scene (SAR band uses a documented backscatter heuristic + multiplicative speckle, see the generator script) |

Swap these for real, declared-modality/declared-date GeoTIFFs the moment
`rasterio` and real imagery are available — nothing downstream needs to change
(see `src/ingestion/raster_io.py`).
